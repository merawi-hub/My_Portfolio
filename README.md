# Portfolio Site

Frontend for my portfolio. Vue 3, TypeScript, Vite.

## What's Here

- Home - quick intro
- About - bio and what I'm working with
- Skills - frontend, backend, and tools
- Projects - 4 projects with demos and code
- Contact - email, phone, social links

Works on phone, tablet, desktop.

## Stack

- Vue.js 3 with TypeScript
- Vite
- Custom CSS
- Netlify
- Formspree

## Running Locally

```bash
npm install
npm run dev
```

Build it:
```bash
npm run build
npm run preview
```

## Deployment

Deployed on Netlify with automatic builds from GitHub. The contact form uses Formspree to handle submissions.
